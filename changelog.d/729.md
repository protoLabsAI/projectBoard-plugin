- **Per-candidate oracles can run only changed Python tests (#729).**
  `coder_solve_test_cmd` and `coder_solve_test_paths` commands now accept
  `{changed_tests}`, expanded to sorted, shell-quoted existing test paths from the
  candidate's committed, uncommitted, and untracked changes.
  - **No accidental full-suite run.** Commands using the token skip when no changed
    tests exist or git cannot list changes, with an explicit oracle note. Other
    selected commands still run; all skipped retains the pass-without-tests warning.
  - **Opt-in targeting.** Fixed commands keep their existing behavior, including no
    git lookup when there is no path map. The configuration guide includes a
    two-worker pytest example for keeping candidate checks within the oracle cap.
