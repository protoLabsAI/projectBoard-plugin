- **The board's tools cost half as many tokens on every model call.** An agent sends every board tool's description with each request; the 36 `board_*` descriptions were about 55k characters. They are now about 27k: each one says what the tool does, when to use it over its siblings, and the rules to follow when calling it. The detail (the Ready gate's checks, `waits_for` grammar, `next_action` and `board_dispatch` values, recovery recipes, the task deliver/verify cycle) moved to a new `board-tool-reference` skill the agent loads when it needs it. The leading indentation `@tool` kept on every description line is gone as well. No tool, parameter, default or behavior changed.
