- **A full disk, a read-only filesystem, or a denied filesystem syscall in gate output is
  now read as an environment fault (INFRA), not "the RESULT is broken".** On nerdsville-site
  (card bd-ufs / PR #77) the merged-state re-verify ran 194/194 green, then vitest died with
  `ENOSPC: no space left on device` while writing its output — and the board spent two retries
  and terminal-blocked a card whose PR CI was green. The same classifier #516 uses for a broken
  dependency tree (`broken_dependency_tree`) now also matches `ENOSPC` / "no space left on
  device", `EROFS` / "read-only file system", and an errno-style `EACCES: permission denied,
  (open|mkdir|unlink|rename) '…'` line, so these route through the existing INFRA path: no
  verdict on the code, nothing stamped or spent, next poll retries, CI still gates. EACCES is
  kept narrow — a test assertion that merely contains the word "EACCES" stays a real red — and
  `ERR_PNPM_OUTDATED_LOCKFILE` stays a code verdict as before.
