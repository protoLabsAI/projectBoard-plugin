- **The health sweep no longer reaps live worktrees on boards whose bead prefix isn't `bd-`
  (#461).** The worktree-name parser only recognised `bd-` ids, so on the designSystem
  board (`ds-…`) the slugged dir `feat-ds-vvi-<slug>` read as the id `ds-vvi-<slug>`. The
  store had no such card, and every sweep reaped the tree as an orphan: a drive about to
  run its pre-PR gate, a card in review waiting on its merge gate, a coder stalled
  mid-dispatch. The drive then crashed in the deleted directory. Any `<prefix>-<id>` bead id
  now parses. And the sweep no longer reaps a tree just because the store has no card for
  an id taken from a slugged name, since that proves only that the parse failed. It keeps
  the tree and logs it once. A tree named exactly `feat-<id>` whose card is gone is still
  reaped, and so are done and cancelled cards' trees.
