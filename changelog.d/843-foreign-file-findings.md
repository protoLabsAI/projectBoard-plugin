Review findings that cite a file absent from both the PR diff and the PR's own repository checkout (for example a host-core file the reviewer could see but the coder cannot edit) are now demoted to `uncertain` and non-blocking. They stay in the review history, are logged, and are reported on the card as a file not in this repository, but they never queue a fix round. Files the PR adds, and untouched files that exist in the repository, keep blocking as before; absolute paths or paths escaping the checkout with `..` count as outside it, and an unknown checkout disables the check.
