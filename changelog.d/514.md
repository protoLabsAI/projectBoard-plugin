- **The review gate now keeps the whole card's finding history — re-review and fix prompt
  see every round, not just the last (#514).** The per-card review memory
  (`_review_prior`) used to be OVERWRITTEN each round, so a bounce re-review and the retry
  prompt only ever saw the latest round's findings — and fix rounds flipped back and forth
  (bd-49yo / #513: round 2 reverted round 1's fix, round 3 asked for it back). It is now an
  append-only list of `{round, head, findings}`: the re-review is handed the WHOLE
  round-marked history as `prior_findings` (so it can tell a fixed finding from one an
  earlier fix regressed), and the fix prompt LEADS with every round's findings under
  "satisfy ALL of these at once; do not trade one for another". A legacy single-round value
  (a bare findings list) is still read, wrapped as round 1, and the history clears at the
  same merge / closed-unmerged edges the single prior popped before.
