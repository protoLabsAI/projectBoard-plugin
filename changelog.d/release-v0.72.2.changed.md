- **The board's tools cost half as many tokens on every model call.** The 36 `board_*` tool descriptions an agent sends with each request dropped from about 55k characters to about 27k: each one now states what the tool does, when to use it over its siblings, and the rules for calling it, while the detail moved to a new `board-tool-reference` skill the agent loads on demand. No tool, parameter, default or behavior changed (#648).
- **`create_from_plan` keeps a feature's priority 0.** A plan that sets priority 0 (highest) is preserved; the 2 fallback now applies only when priority is absent or null, instead of silently rewriting 0 to 2 (#645).
- **The planning critic subagent is `plan_antagonist`.** The adversarial planning subagent was renamed `antagonist` → `plan_antagonist` so core's built-in `antagonist` no longer shadows it, with the docs updated to match (#646, #647).
