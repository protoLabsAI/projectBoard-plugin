- **An agent can set per-project policy from chat (#674).** `board_register_project` now takes an optional `settings` map, so an agent can turn on `require_complete_review`, set `release_freeze` or a `review_summon_handle` on a project without the operator hand-editing YAML (which a later Projects-editor save would wipe). The map merges onto the stored entry — unlisted fields, including hand edits and siblings, are preserved — and the reply echoes the stored project so the agent can confirm the save. Unknown keys are refused, and command text stays operator-only: any `*_cmd` (`preflight_cmd`, `setup_cmd`, `format_cmd`, each `coder_solve_*_cmd`) is refused, `local_gate_cmd` still accepts only blank or `"auto"`, and the echo hides an operator's command text from the agent.
