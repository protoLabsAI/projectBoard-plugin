- **The coder timeout counts time the machine spends asleep (#472).** `coder_timeout_s`
  was enforced with `asyncio.wait_for`, which runs on `time.monotonic()`. On macOS that
  clock stops while the machine sleeps, so a coder dispatched during a DarkWake held its
  1800s bound for hours of real time (2,089s to 12,802s on one night). Every outer
  coder-dispatch bound (the public tap, the legacy tap, the untapped dispatch, task
  delegates and self-dispatch) now goes through `worktree.coder_bound`, which uses the
  host's `infra.clock.wait_for`. Its deadline is on a clock that counts sleep, re-checked
  every 15s, so after a wake the bound fires within 15s of the first awake moment past it.
  While the machine is awake it behaves as before. **This raises `min_protoagent_version`
  to 0.185.0**, the first protoAgent with `infra.clock` (#3724). Older hosts are expected to
  upgrade; there is no fallback.
