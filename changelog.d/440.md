With no coder configured, the setup preflight now gives advice the operator can follow.
It used to say "pick a delegate in Settings ▸ Project Board" even on an agent with no
delegates at all — an empty dropdown and no next step, when the fix lived in core's
Settings ▸ Delegates. It now reads the ACP roster: with none, it says to add a coding
delegate in Settings ▸ Delegates (or ask the agent to propose one) before choosing it
here; with some, it names them. An unreadable roster keeps the generic hint rather than
claim there's nothing to pick (protoAgent#3405).
