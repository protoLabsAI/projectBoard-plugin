Add `owner="agent"` to `board_block_feature` for explicit agent-owned holds. These persist as `agent-hold`, display their reason and release action, and do not send terminal operator alerts. Omitted ownership retains terminal/manual behavior; unsupported owners are rejected without mutation. All holds still require explicit unblock.

Preflight recovery checks the card's current block class before releasing a tracked hold, preserving agent and operator holds that replaced a preflight hold.
