- **The card-from-chat form's Create card button works.** The skill's skeleton wrapped the fields in a `<form>` with a submit handler. The inline artifact frame is sandboxed without `allow-forms`, so the browser blocked the submission ("Blocked form submission … 'allow-forms' permission is not set"): the handler never ran, the "Send to chat" confirm never appeared, and nothing reached the agent. The skeleton now uses a `<div>` and a `type="button"` click handler, and the skill says why.
