- **A slow acceptance oracle no longer makes every coder.solve() card unpassable (#459).**
  With no `coder_solve_test_cmd`, solve() judged candidates by the project's full
  `local_gate_cmd`. A gate slower than `coder_solve_test_timeout_s` failed every candidate:
  bd-7aun spent 15 generations on "acceptance tests timed out after 300s", was blocked as
  `transient`, and was auto-unblocked to spend them again.
  - **Unwinnable-oracle guard.** When the oracle is the gate fallback and the preflight
    measured the gate as slower than the solve timeout, that project's cards take the
    plain coder path. The pre-PR gate still runs. It is logged once and shown as
    `preflight.unwinnable_oracle` on `/status`.
  - **Timeout circuit breaker.** Two candidates timing out on the same command stop the
    ladder. The card blocks at once as `oracle-timeout`, with no tier climb, and the sweep
    never clears that class on its own.
  - **Path-scoped oracles.** New `coder_solve_test_paths` maps path globs to test
    commands, e.g. `apps/web/**` → `npm ci && tsc && vitest`, `**` → `gate`. Each
    candidate runs the commands its changed files pick: the first match wins per file, and
    several picked commands run in sequence.
