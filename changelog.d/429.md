Max-mode now rotates past a provider that fails every candidate, instead of climbing a tier.
It used to swallow each candidate's error, so a spent quota or a model the provider refuses
looked like "no candidate produced a diff". That is a capability failure, so the card
escalated, while a working sibling at the same rung sat idle. When every candidate fails on its
provider in the same way, the loop now handles it as it would a single dispatch. It switches to
a sibling, marks a refusing provider, backs off on a quota, or blocks under `dispatch-infra`.
