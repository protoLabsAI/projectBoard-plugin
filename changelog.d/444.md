- **A project can install each worktree's own dependencies (`setup_cmd`).** Board
  worktrees borrow the repo checkout's `node_modules` through symlinks, which hands every
  card whatever that checkout last installed — or nothing, when it has none. Set
  `setup_cmd` (e.g. `npm ci --no-audit --no-fund --prefer-offline`) per project or
  board-wide and every fresh tree the board builds in installs its own before anything
  runs: the card's tree, each Max-Mode and ladder candidate, and the merged-state verify
  tree. The install replaces the borrowed links rather than writing through them into
  the shared checkout, runs under the same sandbox as the gate, and is bounded by
  `setup_timeout_s` (600s); a failed or hung install is killed, logged, and the work goes
  ahead without it. Off by default.
