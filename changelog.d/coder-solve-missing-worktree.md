Fixed `coder.solve` discarding finished candidates when a later candidate's worktree went missing at dispatch. A candidate whose `.g<n>` tree vanished between create and dispatch (seen as `coder dispatch failed: workdir does not exist`) now recreates its worktree once and retries; if it still can't dispatch, it fails ONLY that candidate instead of raising out of the whole ladder — so completed, would-pass siblings are no longer reaped and a one-off worktree/infra error no longer escalates the model-capability tier. Other dispatch failures (provider rate-limit/outage, timeout) still propagate so provider rotation and timeout handling are unchanged. Each failed candidate's verify reason is now logged (a short tail) so an operator can see why it failed.
