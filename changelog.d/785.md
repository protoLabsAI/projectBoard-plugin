- **A cache-only `node_modules` no longer blocks environment preparation (#785).** A tool's cache drop (`node_modules/.cache/…`) in a directory that is not a package root is not counted as an installed environment, so `setup_cmd` is not asked to recreate it and the card does not block. A `node_modules` with package-manager state (`.modules.yaml`, `.package-lock.json`, `.yarn-state.yml`, `.yarn-integrity`), a `package.json` beside it, or any installed package is still required. The stray directory is left in place.
