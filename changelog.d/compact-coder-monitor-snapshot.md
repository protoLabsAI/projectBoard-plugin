- **A finished coder run is saved on its card as a short summary, not a full replay.** Each run's monitor record (the `coder-monitor:` comment the drawer replays) used to carry the live buffer's whole tool history, 10–38 KB per run. On protoEngineer that added up to 21 MB of a 30 MB `issues.jsonl`, which `br` rewrites and snapshots on every board write, so each update took 10–34 s and the board stalled. The saved record now keeps the run's tier, timing, stop reason, verify result, the last 12 tool rows (with a count of how many there were), short answer/thought tails and a clipped plan, capped at 6 KB. The live drawer is unchanged while a run is going.
