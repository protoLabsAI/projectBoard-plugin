- **The gate preflight runs once per project, and once per commit (#456).** Before, the
  tick and an on-demand `board_dispatch` could each start the gate in the same checkout at
  the same time. A 12-minute gate against the 600 s `preflight_timeout_s` then made every
  dispatch wait ten minutes for "indeterminate, allowing dispatch".
  - A second caller now waits for the run already in flight instead of starting another.
  - A pass, or a timeout, stands for the checkout's commit. When the checkout moves, one
    re-check runs in the background while dispatch goes on, and a red result holds the
    project from the next claim.
  - A preflight that can't finish inside its timeout is logged once, is not re-run until
    the checkout moves, and shows as `preflight.slow` on `/status` and in the setup
    advisories.
  - New `preflight_cmd`, per project or board-wide: a cheap command to smoke instead of
    the full gate (lint plus an import check). Blank keeps smoking `local_gate_cmd`.
