- **Stranded work is saved when `.proto` is ignored as a whole but a file under it is
  tracked.** #446 asked `git check-ignore` whether `.proto` was ignored and excluded it by
  name when the answer was no. With `.proto/` ignored (a global or `info/exclude` entry)
  and a versioned file under it (protoAgent tracks `.proto/evolve/`), `check-ignore` says
  no, `git add` still refuses the exclude ("The following paths are ignored … .proto"), and
  every candidate tree of an interrupted solve blocked its card as `stranded-work` for a
  human to clear (bd-fgtf). Staging no longer names the coder scratch at all: it adds
  everything, then resets `.proto`/`.cursor` in the index to HEAD, which never refuses an
  ignored path. The scratch still stays out of saves and PR commits.
