- **A worktree's unsaved work is saved again in repos that exclude the coder's scratch dir
  (#486).** Staging named `.proto`/`.cursor` in the pathspec, and git refuses a pathspec that
  matches only ignored files — so in a repo that excludes `.proto/` (protoAgent does, via
  `.git/info/exclude`) every stranded-work save failed. The board then kept the worktree and
  its branch rather than destroy work, and the next rebuild of that card died on "a branch
  named `feat/<id>.g1` already exists", blocking the card for good. Scratch is now taken out
  of the index after staging instead of being named in the pathspec, which also covers a
  scratch dir the repo excludes but partly tracks — the shape the previous fix (v0.57.1)
  could not see, because `git check-ignore` stays silent about tracked paths.
