A stranded card's finished work can now be published without dispatching a coder.
`board_salvage_feature` and `POST /features/{fid}/salvage` commit what the card's worktree
holds, run the pre-PR gate, push the branch, open the PR (or push onto the card's existing
one) and put the card in review, using the board's own steps. It is an operator override:
the goal, ledger and source-issue checks are skipped, while CI and the review gate still
apply. It works only on a stranded card, and refuses while a drive owns the card or when no
worktree has changes. A red gate publishes nothing unless `force` is set, which marks the
PR as a draft and reports whether GitHub actually made it one. Recovering bd-ezs7's 170
finished lines had needed a coder, on the day the coder delegate was down.
