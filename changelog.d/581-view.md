- **See the usage rules — and which one steered a card — from the console (B7b, #581).** The **Configure → Coder routing** Ladder now lists each project's active `routing.usage_policy` rules read-only (keep *account* under *N*% → prefer *delegate*, for which tiers), each tagged active or inactive from the account's live used-% — "usage unknown" when the host can't report it, never an error. On every rung, the coder the next card opens on carries a **rule N** tag when a usage rule is what steered it there. `GET /routing/effective` reports the same per project: the active rules with their account usage and, per path, the deciding rule. The decision is computed with B7a's own `policy_decision` for the identical inputs, so the view can never disagree with dispatch.
