The board's setup preflight now gives guidance the operator can actually follow
(protoAgent#3405):

- **Zero coding delegates.** With no coder set and *no* ACP delegate on the agent, the hint
  no longer points at the board's own (empty) picker. It says plainly that no coder can be
  selected yet, names the exact core surface — **Settings ▸ Capabilities ▸ Delegates** — and
  that a delegate must be declared there before it can be named as the board's coder.
- **Unbound board.** The unbound-repo hint now names the board panel's own **Projects ▸ Add
  project** path and its onboarding-root prerequisite (core Project onboarding on, with an
  Onboarding root the repo resolves under), while still offering the direct `project_board.repo`
  / `db_path` / `projects:` binding as the alternative that needs no onboarding root.
- **Stale running loop.** When the loop is configured on but running on a stale restart-only
  knob, `setup_status` now exposes an explicit `loop_restart_required` result — distinguishing
  "restart needed to apply" from a loop that is simply configured off — instead of leaving the
  restart-required note as a buried advisory.
