- **Approving a task twice no longer shows an error for an approval that worked (#791).** The approval used to answer only after the task's worktree was removed, and the board kept showing the card in review until then; a second click was refused with `record_verification expects in_review, got 'done'`. Now the board shows the card as done as soon as it is closed, the worktree is removed after the answer is sent, and Approve and Reject are disabled while the request is running. Approving a task that verification already closed returns the card and changes nothing. Rejecting a done card, and verifying a card that is not a task, are still refused.
