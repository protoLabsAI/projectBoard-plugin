- **A task linked to a card now closes when the card does.** The host closes a task once every piece of work it links has finished, and fulfils a directive the same way, but it learns that a board card finished only from a `task.link.closed` event, and the board never sent one (#765). So a task linked to a card stayed in "Doing now" for good and was always counted as driven. The board now publishes `task.link.closed` with the card id and a reason (`merged (#N)`, `done` or `cancelled`) after a card is merged, marked done, verified or cancelled. Every 5 minutes it also checks the host's open tasks for links to cards that have already finished, and publishes for those, so tasks stuck before this release clear without anyone editing them.
