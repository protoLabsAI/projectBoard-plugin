- **A card's coder runs and reviews read back as one run.** Each board coder dispatch opened a root edge of its own on the host's delegation ledger, and reviews weren't on the ledger at all, so one card showed up as several unrelated runs. Every edge for a card now opens under one run id, `board:<fid>`. That covers each coder run and gen, the reviewer dispatch, the review-gate workflow and its reviewer fallback. The whole card comes back from protoAgent's `GET /api/runs/board:<fid>`. A host without `sdk.run_scope` behaves as before.
