- **A coder's `done — <evidence>` requirement rows now count.** The parser took only a
  bare `- r1: done`, so a coder that cited its evidence (`- r1: done — ChatMessageView
  renders it…`) left every item open through both fix rounds and blocked a finished card
  as "requirements unresolved". A `done` may now carry a note after `:`, a dash, or a
  spaced hyphen; a note that opens with a hedge (`— but…`, `— partially`, `— not yet`,
  `— pending`) still closes nothing, as do `done? not yet` and `done-ish`.
- **Stranded work is saved in repos that gitignore the coder scratch.** Staging excluded
  `.proto`/`.cursor` by name even where the repo already ignores them, which makes
  `git add` exit 1 — so every save of a tree's unmerged work failed there, and closing a
  card kept its worktree for hand cleanup. Ignored scratch is no longer named.
