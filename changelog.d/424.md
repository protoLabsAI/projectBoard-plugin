Gate, preflight, acceptance-test, fixups, `git` and `gh` children now get no stdin and run in
their own process group, so a timeout or a cancel kills the whole tree. They used to inherit
the server's stdin, which in the desktop app is a pipe that never closes, and a timeout killed
only the shell. That orphaned hung `pnpm install`s across two boards, the oldest for 19 hours.
On Python 3.12+, `await proc.wait()` then waited on the orphan's pipe, which stranded a drive
for 8 hours. The fixups step's 180s timeout previously killed nothing at all.
