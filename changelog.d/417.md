A GitHub App's advisory check run no longer gates a card. `_is_blocking_check` treated every
check RUN as blocking, on the assumption that advisory third parties publish through the legacy
commit-status API — but Apps publish through the Checks API, so the non-required `QA panel`
verdict from the `protoreview` App bounced cards into escalation and terminal blocks. A coder can
never fix that signal: it reports unresolved review threads, not anything in the diff.
