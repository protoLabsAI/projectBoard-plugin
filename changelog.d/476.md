- **A fix round that changed nothing is a failed attempt, not "coder done" (#476).** On
  bd-524n, a review bounce's coder worked for fourteen minutes and committed nothing. The
  drive still logged `coder done → PR`. The in-process gate re-reviewed the same head clean,
  and the merged-state gate re-ran while the external FAIL it was meant to fix stood. Before
  a card that already owns a PR publishes, the drive now compares the tree with the commit
  the round resumed from (recorded when the round starts, so a coder that pushed its own
  fix is not misread), and logs `head <before> → <after>`. An
  unchanged head with nothing uncommitted is a `NoChangesError`
  (`fix round produced no commit — <branch> is still at <sha>`). It counts toward the
  same-tier retry, the ladder and the block exactly like an empty build, and it is never
  pushed, re-reviewed or re-gated.
