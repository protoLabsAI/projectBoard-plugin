- **The card-writer helper runs on hosts that use a Claude or ChatGPT subscription.** It was pinned to the gateway alias `protolabs/reasoning`, which a host on `anthropic-oauth` or `openai-codex` cannot run, so every helper stopped at startup on its first live batch. It now pins no model and follows the host's own choice (the turn's model, then `routing.aux_model`, then the main model). To give it a stronger model, set `subagents.board_card_writer.model` to a model id your host can run.
- **The card-writer helper splits an issue cleanly and names the right changelog file.** On its first live batch it split three issues but left the original wide card in place, unchained and over the file cap, and it told coders to edit `CHANGELOG.md` in a repo that only accepts `changelog.d/` fragments. When the Ready gate says a card is too broad, the helper now turns that card into the last slice, chains every slice to the one before it, and checks each one. It looks at how the repo records changes before naming a changelog file.
