- **The store can keep only the newest N finished cards in the live view.** `archive_stale` takes a new `keep_done` argument: after the usual age pass, it archives the oldest done and cancelled cards until the newest N remain. The default is 0, which means no cap, so nothing changes until the loop and Settings start passing a value (later parts of #793). Archiving only hides a card: nothing is deleted, and `include_archived=True` still returns every card. A card with no readable close time is never archived and does not count toward N.
