- **The Board shows loading skeletons until its first read lands.** Listing a board can take a second or more. Until now every lane showed its empty state ("Nothing in the backlog.", "No builds running.") with a 0 count while it waited, so the board looked broken. Now each lane shows a few card-shaped placeholders, the List view shows placeholder rows, counts read `–`, and the lanes are marked `aria-busy`. The placeholders use the design system's skeleton from `plugin-kit.css`, which goes static under reduced motion. They appear only on the first load: live refreshes never bring them back. If the first read fails, the placeholders stop and the error callout explains why, and the lanes still don't claim to be empty.
