An ACP adapter's own chatter no longer counts as evidence that the model ran. The pre-model
guard (#339) treated streamed answer text as model work, but codex-acp sends its own "Model
metadata … not found" warning through that channel before calling the model. So a dispatch that
failed seconds after the session started looked like a real attempt, and the card climbed a
tier instead of blocking for triage. Only tool calls, thoughts and token usage count now.
