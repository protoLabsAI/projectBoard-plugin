- **A board card from chat, and a Board that follows it.** A new `card-from-chat` skill answers "add a feature for …" with a small inline form in the chat (an ADR 0118 interactive answer: Project, Title, What and why, Acceptance criteria, Priority). Its **Create card** button proposes the filled values as the user's next message through the console's "Send to chat" confirm. The agent then creates the card, marks it ready and calls the new `board_watch(feature_id)` tool, which publishes `project_board.focus` and navigates the console to the Board view on the main stage. The view rings the followed card in the accent colour with a small "Following" tag and keeps it in view through every lane move until it lands in done (the Done glow plays) or the operator clicks or scrolls the board. Reduced motion scrolls without smoothing and skips the settle-in pulse. A read-only `board_projects` tool lists the registered project names for the form's picker.
