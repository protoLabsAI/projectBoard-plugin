- **Execution tasks run on a coder, in a real checkout.** A task labelled `execute` (or whose spec names a command to run) now goes through the project's coder ladder instead of the board agent itself. It runs in a throwaway worktree of its project, or an empty temp dir, and the worktree is removed on done, cancel or verify. `board_create_task` takes `execute=true` (#654, #655, #657, #658).
- **External review bounces stop burning tiers.** If a coder reads an external QA finding and declines it (a fix round ends with no commit), the card blocks once as "needs operator" instead of climbing the attempt ladder, and the operator can rule the finding out of scope. Pre-existing panel findings are advisory and no longer start a fix round. A blocked card whose PR was merged anyway closes as done on the next reconcile (#653, #660, #661, #662).
- **A coder that is still working isn't killed at the timeout.** When `coder_timeout_s` runs out while the coder is still streaming, it gets 5-minute extensions up to twice the budget. A coder silent for 10 minutes is still killed on time (#663).
- **No more work-location alerts for coder scratch files.** Claude Code task output, `~/.claude`/`~/.codex` state and loose log files outside any repo are no longer recorded as work locations. An unreadable location with nothing recorded about it no longer pages the operator (#650, #663).
