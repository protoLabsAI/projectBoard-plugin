A card left in backlog to wait for its dependencies, or blocked there for the same reason, is
now named once every dependency has closed, in place of sitting invisible. The loop never
looks at such a card again, so it used to wait on a `mark_ready` nobody knew was owed. It now
reads "dependencies closed — promote" (or "blocked — dependencies closed") in the listing,
the console and the agent's working state, with the verb that moves it. It says so when a
dependency was cancelled rather than merged. Nothing is promoted or unblocked for you, and the
new `board_mark_designing` parks a card on purpose so it stops being flagged. When nothing is
claimable, `board_dispatch` now names what is holding the board, where it used to answer a
bare "empty-queue". The agent's working state now carries the board's own hints, which it had
been showing empty, and lists stranded cards after all in-flight work. A block set by hand is
never cleared automatically, and the sweep no longer self-heals any card blocked before it was
ever ready. A hand block's class used to be guessed from its wording, so "waiting on the
network team" read as transient, and the sweep moved the card to ready without the Ready gate.
