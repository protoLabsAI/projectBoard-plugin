A card left in backlog to wait for its dependencies, or blocked there for the same reason, is
now named once every dependency has closed, in place of sitting invisible. The loop never
looks at such a card again, so it used to wait on a `mark_ready` nobody knew was owed. It now
reads "dependencies closed — promote" (or "blocked — dependencies closed") in the listing,
the console and the agent's working state, with the verb that moves it. Nothing is promoted
or unblocked for you. The agent's working state now also carries the board's own hints,
which it was built to show and had been showing empty. A block set by hand, from the tool or
the API, is now never cleared automatically. Its class used to be guessed from its wording,
so "waiting on the network team" read as transient, and the sweep lifted the hold and moved
the card to ready without the Ready gate.
