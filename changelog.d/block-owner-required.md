`board_block_feature` now REQUIRES `owner` (bd-t3286): `agent` when the caller will do or finish the work itself (an `agent-hold` — no operator page, shown as 'agent hold'), `operator` when the next step is the operator's (the manual `terminal` class — pages as before, shown as 'needs you'). The old `operator` default turned an agent's self-hold into a priority-now operator page. A missing or invalid `owner` returns an `Error:` naming both choices and blocks nothing. `POST /features/{fid}/block` accepts an optional `owner` and keeps `operator` as its default, so console/script blocks are unchanged.
