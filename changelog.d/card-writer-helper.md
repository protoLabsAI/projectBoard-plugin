- **Carding a list of issues no longer holds the agent's chat or fills its context.** Asked to put a sprint's issues on the board, the agent read every issue and the code behind it in its own thread before writing a single card; messages sent to it queued for the whole time, and after a few issues it stopped early or created the same card twice. A new `board_card_writer` helper now writes the card(s) for one issue: it reads the issue and the code, creates the card and repairs what the Ready gate's dry run reports. The new `card-github-issues` skill has the agent start one helper per issue in a single background batch, answer straight away, and keep only what needs the whole picture: duplicates across the batch, ordering cards that share a file, and releasing them.
