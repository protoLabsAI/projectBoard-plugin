The docs guard no longer reads the board's own candidate worktrees as shipped source. `worktrees_root` defaults to `.worktrees/` inside the repo the board builds, so a card still in flight contributed its `cfg.get(...)` keys to the "every config key is documented" check — 36 of the 72 modules scanned came from one candidate tree. The guard then failed on clean main over a key that had not landed, which failed the project's gate preflight and held every board-plugin card, including the siblings of the card whose tree caused it. The filter keys on the `.git` pointer a linked worktree carries, so a differently-named `worktrees_root` is covered too.
