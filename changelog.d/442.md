The "no coder" and unbound-repo setup gaps now reach the console with their Configure button.
The board offered the host a `plugin_config` action through an `actions=` keyword that no
protoAgent host has ever had (the host's `report_setup_gap` takes `action=`), so it silently
fell back to the plain call. The console's banner then showed the message with no way to act
on it. The board now passes `action=` in the host's own shape, with the button labelled
"Configure Project Board". Its tests drive protoAgent's own test registry, whose signatures
match the real host, so a wrong keyword can no longer pass (protoAgent#3438).
