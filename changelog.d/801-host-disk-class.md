- **A full disk is named as the cause.** When the computer ran out of disk space, cards failed to start with a raw git error, were marked as permanently blocked, and the Needs-you page cut off the words "No space left on device". These failures now have their own class (`host-disk`), and the page reads: "This computer is almost out of disk space, so this card can't start. Free up space and it will start again on its own." Other block pages that are too long now keep the end of the error, which usually names the cause, and shorten the middle instead.
