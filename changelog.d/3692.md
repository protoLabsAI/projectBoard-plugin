- **A `coders` rung that names a deleted delegate no longer pauses the board
  (protoLabsAI/protoAgent#3692).** Deleting one rung's delegate used to fail the setup
  `coder` check, so every card stopped, including ones that would have run on rungs that
  were still there. Now only a missing base `coder` pauses the loop. With `coder` blank,
  the loop pauses only when nothing on the ladder resolves. A missing rung delegate is
  skipped at dispatch: the card runs on the rung's other delegates, else the base coder,
  else the nearest live rung. The missing delegate is logged once per rung and name, and
  flagged in the setup status (`coder.missing_rungs`, `coder_rungs_hint`) with the rung.
