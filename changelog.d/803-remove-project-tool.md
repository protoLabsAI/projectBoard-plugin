- **An agent can remove a retired project from chat (#803).** New tool `board_remove_project(name)` removes a board project whose repo folder is gone or that is no longer used, so the operator does not have to open Settings or call `DELETE /projects/{name}`. It runs the same active-card check as that route (now one shared function, `unused_project_guard`): while a card that is not done or cancelled still uses the project it refuses, names the cards and removes nothing. The reply says the new default project if it changed and whether a host work-folder entry (managed project or `filesystem.projects`) still points at the folder, naming its path. `DELETE /projects/{name}` additionally returns `repo`, `previous_default_project` and `host_entries_left`.
