- **The board no longer slowly freezes the desktop app while cards are building.** The "building" dot on in-progress cards and the shimmer on pending cards ran forever as animations that make the page repaint every frame (a growing glow drawn with `box-shadow`, and a moving `background-position`). In the desktop app's web view that kept the board using about 8% CPU, and its memory grew by roughly 50 MB a minute for as long as the board was open, until the app locked up. Both now animate only `transform` and `opacity`, which the GPU compositor runs without repainting, and a test keeps every infinite animation on the board that way. They look the same.
