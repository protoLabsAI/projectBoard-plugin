- **`board_create_feature` and `board_update_feature` now explain the `(new)` marker.**
  A file a card will create (in a changesets repo, the `.changeset/*.md` on nearly every
  card) has to carry `(new)` after its path, or `board_mark_ready` refuses it as a
  nonexistent path. Only that refusal used to say so, which cost a round trip per card.
  Both tools' docstrings now describe the marker with an example, and the create/update
  reply flags an unmarked, missing path straight away (see the Ready-gate dry run),
  naming the marker in the fix.
