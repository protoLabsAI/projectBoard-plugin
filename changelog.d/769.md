- **Agents can read a building card's live coder progress.** `board_get_feature` shows only
  `state: in_progress` for a card being built, and the drawer's
  `GET /features/{fid}/progress` route needs the operator bearer, so a managing agent got 401
  and had to guess from `ps` whether a long-running coder was still working. New read-only
  tool `board_feature_progress(feature_id)` reads the same in-process monitor buffer and
  returns the latest gen's `gen`, `tier`, `elapsed_s`, `done`, `current_tool`, its latest
  tool call or narration line, `idle_s`, `last_activity_at` and the card's `assignee`, with
  text fields capped. A card with no drive in memory answers `live: false` with "no live
  drive for this card in this process". No network, no bearer, no mutation.
