- **With the review gate on, the board's PR stays a draft until its own gate is clean.** The board used to open a normal PR and run its gate a few minutes later, so an external review panel (the fleet QA panel) reviewed every head the gate was about to send back for a fix round. On the fleet that was about 17% of the panel's time and almost half of its cancelled reviews. Now the card's first PR opens as a draft, fix rounds stay draft, and the gate marks it ready when it is clean (or when it cannot judge at all). Only a PR the loop drafted itself is un-drafted; a draft you set by hand stays one. `draft_until_review: false` restores the old behaviour.
