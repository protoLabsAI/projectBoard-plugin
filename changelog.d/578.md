- **Set "Codex only" from the console, no YAML (B4, #578).** The board page has a new **Routing** tab. It shows, per project, the effective coder route for each lifecycle path — `implement`, `fix (CI/review)` and `escalate` restricted by `routing.exclusive`, with `review` and the helper paths marked not covered — plus, per rung, which sibling the next dispatch opens on and why (round-robin, down-marked, `headroom ≥N%`, or exclusive), and each delegate's live down mark and subscription headroom ("unknown" when the host can't report it, never an error). An operator control sets the exclusive set from the configured delegates ("Codex only" is one click) or clears it to restore the full ladder. It reads `GET /routing/effective` and saves through B3's guarded, audited `PUT /routing`, so validation and the audit trail apply and the change is live at once; a refused save is shown inline and changes nothing. The "opens on X because Y" reason is computed with the loop's own `prefer_live_sibling`/`prefer_headroom_sibling`, so the view can't drift from dispatch.
