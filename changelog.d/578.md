- **Pick which coders build from the console, no YAML (B4, #578).** **Settings → Plugins → Project Board → Configure → Coder routing** shows one card per coder, with its provider state, its subscription usage ("Usage unknown" when the host can't report it) and an **Allowed to build** switch. A switch saves at once through B3's guarded, audited `PUT /routing` and applies from the next card, so switching opus off is "Codex only" in one click. With every coder allowed there's no exclusive set, and the last allowed coder can't be switched off. A refused save shows inline and changes nothing. Below the cards, the ladder appears once for each group of projects that route the same way, listing each rung's coders in order and which one the next card would open on. That pick is computed with the loop's own `prefer_live_sibling`/`prefer_headroom_sibling`, so the view can't drift from dispatch.

- Effective-route previews honor the base-coder fallback and the live round-robin cursor without consuming a dispatch turn.
