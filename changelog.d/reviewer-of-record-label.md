- **With the review gate on, the board labels its PRs `reviewer-of-record:board`.** On board PRs the board's own review gate caught 16 real defects in a 24-finding sample; the fleet QA panel caught 1 of them in full, and spent about half its time reviewing board PRs. With the label, a QA panel configured for it carries the gate's `board/review-gate` verdict instead of reviewing the PR a second time. It still reviews any head the gate never looked at. The label is created in the repo if missing and never blocks opening the PR. `reviewer_of_record_label: ""` turns it off.
