- **A task assigned to the board's own agent by its host name now wakes it, and a parked task that goes quiet is flagged (#750).** A task whose assignee matches the loop's `AGENT_NAME` (case-insensitively) is self work: it dispatches through `HOST.invoke` like a `self`/`agent` task instead of parking in progress unnoticed. Sister agents, humans and empty assignees are unchanged. Every task park — a human or unassigned task, a name the board cannot dispatch, a self task on a host with no invoke seam, or a self task waiting behind another self run — now writes one plain-words comment on the card saying why it parked and who has to deliver it. The health sweep flags a parked task that has been in progress with no activity for longer than the new `task_stall_minutes` (default 30; `0` turns it off) with one `task-stalled:` comment naming the minutes, the assignee and the number of open dependent cards. The comment is written once per stall, and the card is neither blocked nor requeued. Self tasks keep the existing requeue path.
