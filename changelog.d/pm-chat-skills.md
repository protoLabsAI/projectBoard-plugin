Three operator chat commands ship with the board: `/standup`, `/triage-github` and `/grill-me`. `/standup` writes a status report from the board and open PRs: epics as phases with progress bars, then open PRs, the critical path, what's gated and what needs the operator's call. `/triage-github` scores an issue queue on Value, Level of Effort and Risk, skips issues already on the board, buckets the rest, and creates cards for chosen quick wins only when asked. `/grill-me` (the `grilling` skill) stress-tests a plan one question at a time and creates nothing until the operator confirms. All three use the board and GitHub tools, with no shell steps. Before this, protoEngineer had these as workspace skills imported from Claude Code: they weren't chat commands, and their `git`/`gh`/`br` shell steps couldn't run on a host with no shell.
