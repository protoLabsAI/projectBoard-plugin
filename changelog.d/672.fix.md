Treat a 500 / "Internal Server Error" as transient, so an intermittent push failure retries instead of wedging the card. The transient rule matched `\b50[234]\b` — 502, 503 and 504 — so a plain 500, the canonical retryable server fault, fell through every rule to `terminal`, which is never retried and never self-healed. Two cards lost a verified build to a GitHub push 500 inside 77 minutes, and pushing the identical commit minutes later succeeded. 501 stays terminal (Not Implemented is a contract error), and a bare `remote rejected (failure)` stays terminal because that is also what a genuine refusal looks like.
