- **New Overview tab is the first stop in Configure, answering "is the board working?" (settings overhaul S1a, #611).** **Settings → Plugins → Project Board → Configure → Overview** is a plugin-owned page that leads with a **Board** switch — turn building of ready cards on or off, saved through the guarded settings route, with the current state spelled out in plain words ("On — picking up ready cards" / "Off — the board and tools still work, nothing is dispatched"). Below it, **Now** shows live counts of building / in review / blocked / waiting cards, each a link to the board filtered to that lane. **Problems** lists setup gaps, held projects, stale or dirty base checkouts and a stalled claim as one plain line apiece with what to do about it (and a **Re-check** that re-runs the setup preflight) — never a raw error string on its own. A **pending-restart** callout names, by their plain labels, any saved settings that only take effect after a restart, and says how to restart (the restart button itself lands in a follow-up). The page holds no board data — every read and write goes through the authenticated plugin-kit fetch after `initPluginView`, and colours come entirely from design-system tokens, so it works in light and dark. The board on/off switch (`loop_enabled`) moved here from the Automation tab's generic settings list.
